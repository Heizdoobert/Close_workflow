# Security Policy

## Reporting a vulnerability

Do not open a public GitHub issue for a security problem.

Report it privately to the maintainer at the address below. The maintainer
will set this address before the first public release:

- Private reporting address: _to be set by the maintainer_

Until an address is set, use GitHub's private vulnerability reporting on this
repository (Security tab, "Report a vulnerability"), if it is enabled.

Include the affected version or commit, the steps to reproduce, and the impact
you expect. Do not include real secrets, tokens or customer data in the report.

## Supported versions

| Version | Supported |
| ------- | --------- |
| 0.5.x   | Yes       |
| < 0.5   | No        |

Only the latest release on `main` receives fixes.

## Response expectation

- Acknowledgement of your report: within 7 days.
- Triage and a severity estimate: within 14 days.
- Fix or mitigation for confirmed issues: as soon as practical, depending on
  severity. The fix is credited in the changelog unless you ask otherwise.
